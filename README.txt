PhotoTrace pour Vercel

Déploiement simple :
1. Décompresse cette archive.
2. Dans Vercel, choisis Add New > Project et importe un dépôt GitHub contenant ces 4 fichiers, OU utilise la fonction de déploiement CLI depuis un ordinateur.
3. Framework Preset : Other ; Build Command : laisser vide ; Output Directory : . (racine du projet).
4. Déploie, puis ouvre le domaine .vercel.app sur Safari iPhone.
5. Dans Safari : bouton Partager > Sur l’écran d’accueil.

Cette version n'envoie pas la photo à un serveur. Elle effectue des recherches textuelles via des moteurs publics. La recherche inversée par image n'est pas intégrée.
